# AI Production Incident Investigator — Frontend

This is a frontend-only React/Vite prototype based on the project workflow in the supplied project PPT.

## Includes
- Dashboard
- Incident detection view
- Investigation pipeline
- Evidence/log view
- Metrics
- Adaptive historical retrieval view
- Root-cause analysis
- Controlled remediation approval
- Recovery verification
- Incident report

## Run
Open this folder in VS Code, open a terminal in the project folder, then run:

npm install
npm run dev

The frontend uses mock data for the UI. Backend, PostgreSQL, AI/RCA, and real dataset integration are intentionally not included in this frontend-only version.
